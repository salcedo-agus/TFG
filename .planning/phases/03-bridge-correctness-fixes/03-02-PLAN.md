## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-02-SC | Tampering | DLL search path | high | mitigate | build/-only load via `os.add_dll_directory(BUILD_DIR)` (D-08); absolute-path CDLL; MINGW_BIN env lookup removed from Python — the env var survives ONLY as a Makefile build-time override (D-09), never a runtime DLL-search input |
